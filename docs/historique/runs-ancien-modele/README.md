# Setlist : l'ancien modèle (proto 1 à 3)

Archive **figée** : les règles, écrans, conception, plan et protos 2 et 3 du mode Run avant la refonte « la Série » (novembre 2026), quand une manche se passait en remplissant une jauge (objectifs en pourcentage, multiplicateurs par manche), qu'on choisissait la difficulté de la suivante (Facile, Normal, Mélomane), qu'on jouait des cartes (coups de pouce, Échange) et qu'une partie finissait par un disque de victoire. Ce modèle n'existe plus dans le code ; les liens relatifs de ces documents ne sont pas tenus à jour.

La référence actuelle est [`docs/runs/`](../../runs/README.md). Les captures de `maquettes/app/` ont été prises le 06/11/2026 sous l'ancien modèle (pochettes remplacées par un aplat depuis #517).
