# Survie : l'ancien modèle (proto 1 à 3)

Archive : les règles, écrans, conception, plan et protos 2 et 3 du mode Run avant la refonte « la Série » (novembre 2026), quand une manche se passait en remplissant une jauge (objectifs en pourcentage, multiplicateurs par manche), qu'on choisissait la difficulté de la suivante (Facile, Normal, Mélomane), qu'on jouait des cartes (coups de pouce, Échange) et qu'une partie finissait par un disque de victoire. Ce modèle n'existe plus dans le code.

Les documents et leurs captures (prises le 06/11/2026 sous l'ancien modèle) ont été retirés du dépôt ; git les garde. Dernier commit qui les contient : `bfbd60f9`.

| Fichier | Contenu |
|---|---|
| `regles.md` | les règles à jauge, difficultés et cartes |
| `ecrans.md` | les écrans de l'ancien modèle |
| `conception.md` | la conception technique de l'ancien modèle |
| `plan.md` | le plan et les décisions du mode jusqu'à la refonte |
| `proto2.md`, `proto3.md` | les protos 2 (difficultés, cartes) et 3 (Échange) |
| `maquettes/` | maquettes et captures de l'ancien modèle |

Pour les relire : `git show bfbd60f9:docs/historique/runs-ancien-modele/regles.md` (même chemin pour les autres), ou tout le dossier : `git archive bfbd60f9 docs/historique/runs-ancien-modele | tar -x`.

La référence actuelle est [`docs/runs/`](../../runs/README.md).
