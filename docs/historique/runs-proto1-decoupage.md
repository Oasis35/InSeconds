# Run (Platines) : découpage du proto 1 en PR

Chantier terminé : le proto 1 a été livré le 27/10/2026, sur invitation. Ce document est **figé** et ne décrit plus forcément le code. La référence est le [`CLAUDE.md`](../../CLAUDE.md) racine, ses deux compagnons et le dossier [`docs/runs/`](../runs/README.md) ; la feuille de route du mode est dans [`runs/plan.md`](../runs/plan.md).

Chaque PR arrivait en prod par le merge `env/staging → main`. Aucune ne devait laisser une route de jeu ouverte, ni collecter une donnée que `/privacy` ne mentionnait pas. Chaque PR mettait à jour la doc qu'elle touchait. Les PR étaient étiquetées `run`. La description de chaque PR commençait par `Closes #<sous-ticket>` puis `Part of #360`. Le sous-ticket se fermait à la main au merge.
